        HELP

        What happens next?

        How do automatic backups work?

        With normal backup firmware installed, finish copying files into the stick’s QA folder and leave it plugged in. The stick waits for copying to settle, then uploads new or changed files during its configured backup time. It reads the cloud copy back before recording success. Your original files stay on the USB.

        Bluetooth is for setup and recorded status. Wi-Fi carries the backups. A setup-only test image does not run normal backups.

        Does Disconnect mean unplug the USB?

        No. The Disconnect button closes this page’s Bluetooth session. Leave the USB plugged in. Its short setup window also closes automatically; that alone is not a failed backup.

        What if Wi-Fi needs an Accept page?

        Joining an open network does not prove internet access. When supported by the installed firmware, the sign-in helper guides your phone through a temporary connection via the stick. You complete the venue’s page yourself. A phone hotspot is a fallback when the venue does not permit this connection.

        What does the backup record prove?

        The last verified time refers to a file the stick checked on the cloud. Recorded counts may come from a partial or earlier scan. “Wi-Fi connected” and “cloud settings saved” do not prove that every file has been backed up.

        Cloud fields appear only on firmware that supports private owner cloud setup. There are no file transfers on this page. Owner keys and passwords are not saved by this page. If the connection ends during Save, its outcome may be unknown; reconnect to read the settings revision before retrying.
